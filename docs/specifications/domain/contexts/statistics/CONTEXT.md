# Statistics

Collecting returns from institutions and turning counts into official, published figures. A core subdomain: official statistics are what an EMIS exists to produce.

## Language

**Collection**:
One cycle of gathering data from respondents with a given instrument.
_Avoid_: Survey, data call

**Census**:
A collection that covers every institution once a year at one reference date.
_Avoid_: Annual survey, school return

**Instrument**:
The versioned definition of a collection's items, rules, reference date, window and expected respondents.
_Avoid_: Form, questionnaire, template

**Return**:
One institution's response to an instrument.
_Avoid_: Submission, survey response

**Attestation**:
The head of an institution's confirmation that a return is complete and correct.
_Avoid_: Sign-off, certification

**Snapshot**:
A locked, versioned copy of data as at a reference date, from which official figures are computed.
_Avoid_: Extract, dump

**Measure**:
A named calculation over stored counts, defined once.
_Avoid_: Metric, KPI, statistic

**Indicator**:
A measure with published metadata, often one defined internationally.
_Avoid_: KPI, metric

**Publication**:
The open release of aggregate statistics.
_Avoid_: Open data dump, report, extract
