# Reference (shared kernel)

The terms every context shares: time, codes, geography and the idea of a registry. Changes here affect every context, so they are reviewed by all stewards.

## Language

**Academic period**:
A school year, or a term within it, to which enrolments, postings and results belong.
_Avoid_: Session, semester (unless that is the local term)

**Reference date**:
The date as at which stocks are counted for a collection or an indicator.
_Avoid_: Census day, snapshot date, as-of date

**Code list**:
A governed, versioned set of allowed values for a coded attribute; a code is retired, never reused or given a new meaning.
_Avoid_: Lookup, enum, dropdown

**Crosswalk**:
A versioned mapping from a local classification to an international one.
_Avoid_: Mapping table, conversion

**Administrative area**:
A unit of the versioned administrative geography, such as a district.
_Avoid_: Region (unless that is the local term), zone

**Registry**:
The single authoritative store of one kind of master record (institutions, sites, persons, posts).
_Avoid_: Register, roster, directory, master list

**External register**:
An authoritative list held by another authority, such as a civil register, read through an adapter.
_Avoid_: Registry (which is ours), source system

**Data subject**:
The person a record is about.
_Avoid_: Owner, user
