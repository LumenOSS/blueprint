# Guides

These guides help you get things done with the blueprint, step by step.
Each one assumes you already know the [core concepts](../concepts/README.md),
and each points you to the [specifications](../specifications/README.md) it
applies.

| Guide | Use it to |
| --- | --- |
| [Building an implementation](building.md) | Turn the blueprint into a running platform, in a build order generated from the dependencies |
| [Example products](products/README.md) | See a workload run through every layer, and check a new product against the checklist |
| [Backfill](backfill.md) | Load history and reprocess data safely |
| [Lessons](lessons.md) | Avoid the failures that shaped the design |
| [Reviewing](reviewing.md) | Follow the review towards 1.0.0, and give a verdict on a page, a clause or a decision |
| [Translating](translating.md) | Translate the documentation, or edit a page that has translations |
